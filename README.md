# SauceDemo Login Functionality Testing

## Project Overview
This project focuses on testing the login functionality of SauceDemo, a sample e-commerce website. The purpose is to verify that the system correctly authenticates valid credentials and rejects invalid or incomplete credentials.

**Website:** https://www.saucedemo.com/

## Testing Objective
To verify that SauceDemo correctly validates login credentials and restricts access for invalid credentials.

## Testing Scope
Testing is limited to login authentication, including:
- Login with valid credentials
- Login with invalid usernames or passwords
- Login with empty fields

Other website features, such as product selection, cart functionality, and checkout, are outside the scope of this project.

## Testing Approach
- **Testing Type:** Manual Testing
- **Testing Technique:** Negative Testing
- **Test Documentation:** Test cases and execution results documented in Excel
- **Test Evidence:** Screenshots captured during test execution

## Test Environment
- **Website:** SauceDemo
- **Browser:** Google Chrome
- **Operating System:** Windows 11

## Test Results
Six test cases were executed to verify the login functionality. All six test cases passed.

No confirmed defects were identified during the executed tests.

## Limitations
Testing was limited to login authentication. Other website features and workflows were not tested.

## Conclusion
All six executed test cases passed. The results confirmed that valid credentials allowed successful login, while invalid or incomplete credentials were rejected. Further testing is required to evaluate features outside the defined scope.
